# Zaafi - Banking Web App  

Zaafi is a modern and interactive banking application built to simplify financial management. It includes essential features like user login, transaction history, money transfers, and loan requests while offering a responsive design and support for international users through currency and date localization.

## Features  
- **User Login**: Secure access for individual accounts.  
- **Account Management**:  
  - View account balance, incomes, outcomes, and transaction history.  
  - Send money and request loans dynamically.  
- **Internationalization**: Localized dates and currency formats.  
- **Session Management**: Automatic logout after inactivity.  
- **Responsive Design**: Optimized for desktop and mobile devices.  

## Project Highlights  
Zaafi showcases advanced JavaScript concepts, including:  
- DOM manipulation for interactive features.  
- Array methods (`map`, `filter`, `reduce`) to handle and display transaction data.  
- Event-driven programming for seamless user interactions.  
- Local and session storage for session management.
